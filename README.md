# 🚀 TaskFlow - Project Management System

> A full-stack Jira-inspired project management application built with the MERN stack. Streamline your team's workflow with intuitive project and task management.

## 📌 Live Demo

## ✨ Features

### 🔐 Authentication & Security
- Secure JWT-based authentication
- Protected routes and API endpoints
- Password hashing with bcrypt
- Session management

### 📁 Project Management
- Create, read, update, and delete projects
- Project descriptions and metadata
- View all projects in a clean grid layout
- Project-specific task management

### ✅ Task Management
- Create tasks within projects
- Assign tasks to team members
- Track task status (Todo → In Progress → Done)
- Pin important tasks for quick access
- Task descriptions and details

### 👥 Team Collaboration
- Add team members to projects
- Assign tasks to specific members
- View task assignees with avatars
- Personal "My Work" dashboard

### 💼 My Work Dashboard
- View all tasks assigned to you
- Filter tasks by status
- Quick status updates
- Track your productivity
- See task statistics

### 🎨 Modern UI/UX
- Clean, responsive design with Tailwind CSS
- Intuitive navigation
- Smooth animations and transitions
- Mobile-friendly layout
